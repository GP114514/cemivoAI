# AI 软件渲染引擎版

本次重新制作 40 秒英文原理片，以“AI as a Software Rendering Engine”为核心，展示完整画面、点击及输入如何形成渲染请求，再由 AI 规划布局、神经模型生成像素，并根据任务结果更新画面。

保留模拟指针和点击波纹；使用经过哈希校验的真实模型 PNG 和实际布局数据；局部更新的范围外变化仍为 0 像素。像素逐步显现和神经网络符号是 JS 原理动画，不代表实际模型推理顺序、激活值或速度。
